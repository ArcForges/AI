# Code of conduct

Treat contributors with respect. Keep technical disagreement focused on the change and its evidence. Harassment, threats, discriminatory abuse, deliberate disclosure of private information and spam are not accepted.

Maintainers may edit or remove disruptive content and restrict participation. Use GitHub's report-content controls for abusive content, or contact the repository owner through GitHub. Keep private information out of public issues. Use the separate security reporting channel only for security vulnerabilities.
